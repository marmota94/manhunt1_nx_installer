manhunt1_nx SD installer

Builds an SD-card package for manhunt1_nx, the Nintendo Switch homebrew port of the original Xbox Manhunt, from your own copy of the game. Everything happens in this browser tab. Nothing is uploaded.

Loading port release…

1. Choose your game

Use your own original Xbox copy of Manhunt: a disc image (.iso, either an xiso or a full Redump image) or a folder extracted from it that contains DEFAULT.xbe, audio and levels.

2. Build the SD package

Every game file is checked against the port's SHA-256 list while the ZIP is written. You need about 2.5 GB of free disk space.

0%

Save ZIP

3. Install on the Switch

  1. Delete any old switch/manhunt1_nx/game folder on the SD card.
  2. Extract the ZIP at the root of the SD card.
  3. Hold R while opening a game to enter the homebrew menu or Sphaira in title-takeover mode, then start manhunt.nro.
  4. To quit, hold ZL + ZR + Plus + Minus for 1.5 seconds.

Settings

Settings are in switch/manhunt1_nx/manhunt.env, one KEY=VALUE per line. Edit it with any text editor.

MANHUNT_WIDESCREEN=1
16:9 widescreen: a wider 3D view, with the HUD, menus and movies kept at 4:3 in the centre. It is on in the release. Remove the line for 4:3.
MANHUNT_LANGUAGE
The console language the game reads: english, japanese, german, french, spanish or italian. The release sets spanish; without the line the game uses english.
